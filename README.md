# RealtyFlow Coursework

Стартовый проект курсовой работы по теме:

> Программное средство для организации деятельности агентства недвижимости города

Проект выполнен как веб-приложение на Rust с серверным рендерингом HTML и PostgreSQL в качестве СУБД. Текущая версия ориентирована на требования курсовой: многопользовательский режим, разграничение прав, журналирование, отчеты, резервное копирование, редактирование данных и администраторский SQL-режим.

## Что реализовано

- Rust-приложение на `axum` с HTML-интерфейсом и формами.
- 15 таблиц предметной области.
- роли пользователей: `admin`, `realtor`, `guest`.
- совместимость со старыми ролями `manager`, `analyst`.
- добавление, редактирование и удаление объектов, собственников, клиентов и сделок.
- журнал действий пользователей и аудит изменений по ключевым таблицам.
- триггеры и функции для автоматизации обработки данных.
- представления, сохраненные запросы и администраторский SQL-раздел.
- печать и экспорт отчетов в `CSV` и Excel-совместимый формат `XLS`.
- сценарии резервного копирования и восстановления БД.
- готовые тестовые данные для демонстрации.

## Быстрый старт

1. Выполнить локальную подготовку проекта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup-local.ps1
```

Скрипт создаст `.env`, если его нет, и проверит наличие `cargo`, `psql`, `pg_dump`, `pg_restore`.

2. После установки PostgreSQL client tools и Rust инициализировать БД:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/init_db.ps1
```

3. Запустить приложение:

```powershell
cargo run
```

Также доступны задачи VS Code: `setup-local`, `init-db`, `cargo-run`.

## Подготовка окружения

1. Установить Rust через `rustup`.
2. Установить PostgreSQL и утилиты `psql`, `pg_dump`, `pg_restore`.
3. Создать базу данных:

```sql
CREATE DATABASE realty_agency;
```

4. Скопировать `.env.example` в `.env` и при необходимости изменить `DATABASE_URL`.

## Инициализация БД

Выполнять SQL-файлы в таком порядке:

```powershell
psql -U postgres -d realty_agency -f sql/01_schema.sql
psql -U postgres -d realty_agency -f sql/02_seed.sql
psql -U postgres -d realty_agency -f sql/03_views_and_automation.sql
psql -U postgres -d realty_agency -f sql/04_roles.sql
```

Файл `sql/05_reporting_queries.sql` содержит готовые сложные выборки для демонстрации и пояснительной записки.

## Как проект соотносится с заданием

- учет объектов, клиентов, собственников и сделок реализован через отдельные сущности и формы `CRUD`;
- классификация объектов поддерживается справочниками категорий, статусов, состояний и районов;
- поиск и фильтрация реализованы в разделе объектов и SQL-функции `search_properties`;
- отчеты реализованы через представления `vw_property_catalog`, `vw_owner_portfolio`, `vw_sales_summary_by_month`, `vw_manager_performance`;
- администратор может выполнять произвольные `SELECT/WITH/VALUES`-запросы через интерфейс приложения;
- разграничение прав доступа обеспечивается ролями приложения и SQL-ролями PostgreSQL;
- журналирование действий обеспечивается таблицей `audit_log`, приложением и триггерами БД;
- резервное копирование и восстановление поддерживаются скриптами `scripts/backup.ps1` и `scripts/restore.ps1`;
- печать и экспорт отчетов доступны из интерфейса в `CSV` и `XLS`.
